LightCreator

Laser engravers and cutters

Works on a real machine v0.3.5

An open-source alternative to LightBurn. Cut layers, line, fill and image engraving with six dithering methods, a camera overlay, a toolpath preview with the time of the job and a G-code viewer.

  • GRBL and Marlin over a serial port or the network
  • Ruida / Trocen jobs as PLT / DXF
  • Tested on a Sculpfun S9 diode laser
Download Source on GitHub

MillCreator

CNC milling machines

Works on a real machine v0.3.7

Layers with an operation (outside, inside, on the line, pocket, drill) and a bit from the library, a 3D preview of the material, picture engraving and 3D relief, streaming to GRBL with probing and macros.

  • Bit library with seven kinds of bits
  • 3D view and an animated simulation
  • Tested on a TwoTrees TTC450Pro
Download Source on GitHub

PenCreator

Pen plotters

Early: not yet tried on a real plotter v0.3.7

Pens as layers: colour, width, speed, outline and fill lines. A plot preview with the pen-up moves, the number of lifts and the time, stroke ordering to shorten the moves, and a pause to change the pen.

  • Z axis or a servo pen lift
  • Pen library with the mark each pen makes
  • Pictures drawn with dots or hatching
Download Source on GitHub

Built together, on baseCreator

All three programs share one core, so a new tool or fix lands in every one of them.

30 languages

Polish, English, German, Spanish, Chinese, Hindi, Greek and more. Switch in the start window.

Windows, macOS, Linux

Installers for Windows, .dmg for Apple silicon and Intel, .deb and .tar.gz for x86_64 and ARM64.

Free and open

MIT or Apache-2.0. No account, no subscription, no telemetry.

Imports what you have

SVG, PDF and Illustrator files, bitmaps with tracing, LightBurn projects (.lbrn2) and UGS Designer designs.

A shared clipart gallery

310 pictures in 9 categories, your own pictures and online search of open icon collections.

One project file

A .cre project keeps one drawing with a section for every program, so you can laser a part and mill another.

A G-code viewer

Open any G-code file from the start window, without a project: flat or in 3D, with travel moves, colour by height, size and time.

A navigation cube

Click a face, an edge or a corner of the cube in a 3D view to look from there, the same as in FreeCAD.

Control the machine

Jogging, probing, start from a line, macros, the firmware settings and calibration, over a serial port or the network.

Plugins

Install generators, importers and G-code postprocessors from the official list with one click: Settings → Plugins… → Official plugins. Each one runs in a sandbox and works in every program that can use it.

See all plugins
  • Circuit boards from KiCad, Gerber, EAGLE and EasyEDA
  • Boxes with finger joints for a laser
  • Nets of boxes to cut out of card
  • Fractals, gears, holes on a circle
  • STL projection, x,y point files
